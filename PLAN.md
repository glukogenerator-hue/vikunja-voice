# Vikunja Voice — Android-агент «говорю → задача в Vikunja»

*План от 2026-11-15. Цель выбрана пользователем: свой Kotlin-план (путь C).*

## Цель

Одно Android-приложение: держишь кнопку, говоришь по-русски «послезавтра в десять позвонить в налоговую» — в Vikunja падает задача с заголовком, датой и временем. Дальше — список задач, галочка «сделано», виджет, wake word.

## Как это работает

```
[Кнопка записи] → аудио → STT → текст
                                   ↓
                     Ollama (qwen, tools) разбирает фразу:
                     title / due_date / проект
                                   ↓
                     POST {vikunja}/api/v1/projects/{id}/tasks
                                   ↓
                     Экран: «✅ Задача создана — послезавтра 10:00»
```

- **STT (вход):** M1–M2 — системный Android `SpeechRecognizer` (русский, ноль настройки, работает сразу). M4 — переключатель на серверный Whisper (приватно), M5 — офлайн Vosk ru-small (~45 МБ) + wake word.
- **Разбор фразы:** локальный `RussianDateParser` в телефоне (без сети и LLM): «сегодня/завтра/послезавтра», «через N дней/недель/месяцев/часов/минут», «в пятницу», «20 ноября», «двадцатого ноября», «в 10», «в 10:30», «в 10 вечера», «в полдень». Дата уходит в Vikunja как `due_date` (UTC), из заголовка лишние слова удаляются. Фолбэк — заголовок как сказано.
- **Vikunja API:** токен из Настройки → API Tokens (scope Tasks), `Authorization: Bearer tk_...`. Создание: `POST /api/v1/projects/{projectId}/tasks` `{title, due_date, ...}`. Список/выполнено: `GET /api/v1/tasks/all`, `POST /api/v1/tasks/{id}` (isdone).
- **Сеть:** дома — LAN; вне дома — WireGuard на VPS 185.68.93.84 (сервер WG уже есть, добавить профиль для телефона).

## Стек

- Kotlin + Jetpack Compose, один экран чата-захвата + экран настроек. minSdk 26, target 35.
- OkHttp (REST), DataStore (настройки: адреса, токен, проект по умолчанию).
- Сборка без Android Studio: JDK 17 + Android cmdline-tools + Gradle wrapper → `gradle assembleDebug` → APK → adb install. (Всё ставлю сам на этой машине.)

## Этапы (каждый = рабочий результат)

| Этап | Что делаем | Готово, когда |
|---|---|---|
| **M1. Скелет + голос** (1 вечер) | Проект, кнопка записи, SpeechRecognizer → текст на экране, настройки адресов | Говоришь — видишь текст |
| **M2. Задачи** (1 вечер) | Экран подключения: адрес + токен → `GET /projects` → выбор проекта → только потом запись; `POST` задачи в выбранный проект, экран подтверждения | «Позвонить маме» → задача в Vikunja |
| **M3. Даты** ✅ (вечер 2026-11-15) | Локальный разбор фразы в телефоне (`RussianDateParser`): даты/время → `due_date`, заголовок очищается; 16 юнит-тестов | «послезавтра в 10…» → due_date выставлен |
| **M4. Удобства** (частично ✅) | ✅ Второй экран «Задачи»: список, выполнено/не выполнено, удаление, смена проекта; осталось: Share-target (текст из любого приложения → задача), виджет-кнопка | Захват задачи без открытия приложения |

| **M6. Опционально** | Напоминания Vikunja → уведомления в приложении (webhook), офлайн-режим мелкой моделью | — |

## Что нужно от пользователя

1. **Адрес Vikunja в LAN** (IP:порт) — для M2.
2. **API-токен:** в Vikunja Настройки → API Tokens → создать, права «Tasks» (сделаю вместе на M2).
3. **Телефон для теста** (модель/версия Android) и включённая отладка — APK ставим через adb.
4. Согласие поставить JDK 17 + Android SDK на эту машину (~5 ГБ на C:).

## Решения и заметки

- SpeechRecognizer на M1 — компромисс: быстро, но текст уходит в Google. Пользователь предупреждён; в M5 убираем (Whisper/Vosk).
- Токен Vikunja хранится только на телефоне (DataStore), через сервер не проксируется.
- Даты по-русски парсит LLM, не приложение — надёжнее для «послезавтра», «в следующую среду», «к обеду».
- Всё общение с LLM/Vikunja — по LAN/WG, без интернета в целом приложение работает (кроме Google-STT на M1–M4).
